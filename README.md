# 🏴‍☠️ One Piece Tier List

A full-stack web application that allows users to create and manage their own **One Piece character tier lists**.

Users can register, log in securely, and rank One Piece characters using a drag-and-drop interface.

---

## 🚀 Features

- 🔐 User Registration and Login
- 🔑 JWT Authentication
- 👤 User-specific Tier Lists
- 🏆 Character Tier Ranking
- 🖱️ Drag-and-Drop Character Ranking
- 💾 Rankings saved to SQL Server
- 🧩 Character CRUD API
- 📋 Tier List CRUD API
- 📦 20 One Piece Characters
- 🖼️ Character Images
- 🚪 Logout functionality
- 📱 React-based user interface
